# Town-map profile

A Vietnamese personal portfolio for visitors to explore a software engineer's introduction, skills, projects, and contact links. The town is the navigation: the studio opens projects, the cottage opens the introduction, and the post office opens contact details.

Keep the factual content in `src/content/` unchanged during visual work. The current profile name and project descriptions are user-editable placeholders. The application is a static React/Vite site with local state, no backend, and GitHub Pages subpath support. Every illustrated section has an equivalent HTML navigation button.
